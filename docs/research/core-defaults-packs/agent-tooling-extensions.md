# Extension-format landscape for AI-coding-agent CLIs (verified 2026-09-19)

## 1. Claude Code plugins

**Core.** A plugin is a directory; the manifest `.claude-plugin/plugin.json` is *optional* and only `plugin.json` lives inside `.claude-plugin/`; everything else sits at the plugin root: `skills/<name>/SKILL.md`, `commands/*.md` (legacy flat skills), `agents/*.md`, `hooks/hooks.json`, `.mcp.json`, `.lsp.json`, `settings.json`, `bin/` (added to Bash PATH), plus experimental `workflows/`, `output-styles/`, `themes/`, `monitors/monitors.json` [plugins-reference](https://code.claude.com/docs/en/plugins-reference). Manifest fields: required `name` (kebab-case, drives the `/plugin-name:skill` namespace); metadata `displayName`, `version`, `description`, `author{name,email,url}`, `homepage`, `repository`, `license`, `keywords`, `metadata` (ignored), `defaultEnabled`; component-path overrides `skills` (adds to default), `commands`/`agents`/`workflows`/`outputStyles` (replace default), `hooks`/`mcpServers`/`lspServers` (path or inline); `userConfig` (typed prompts at enable time, `sensitive` values go to Keychain/`~/.claude/.credentials.json`, exposed as `${user_config.KEY}` and `CLAUDE_PLUGIN_OPTION_<KEY>`); `dependencies` with semver [plugins-reference](https://code.claude.com/docs/en/plugins-reference). Path variables: `${CLAUDE_PLUGIN_ROOT}`, `${CLAUDE_PLUGIN_DATA}` (`~/.claude/plugins/data/{id}/`, survives updates), `${CLAUDE_PROJECT_DIR}` [plugins-reference](https://code.claude.com/docs/en/plugins-reference). Skills follow the Agent Skills standard (`name`, `description`, `license`, `compatibility`, `metadata`, `allowed-tools`) plus Claude-only fields (`disable-model-invocation`, `user-invocable`, `context: fork`, `paths`, `hooks`, `arguments`...) [skills](https://code.claude.com/docs/en/skills). `commands/` is deprecated in favour of `skills/` [skills](https://code.claude.com/docs/en/skills).

**Default experience.** `claude-plugins-official` (repo `anthropics/claude-plugins-official`) is auto-registered on first interactive launch; it contains LSP plugins (`typescript-lsp`, `pyright-lsp`, `rust-analyzer-lsp`...), MCP integrations (`github`, `gitlab`, `linear`, `slack`, `vercel`, `supabase`, `sentry`...), `security-guidance`, `commit-commands`, `pr-review-toolkit`, `plugin-dev`, output styles [discover-plugins](https://code.claude.com/docs/en/discover-plugins). Bundled skills ship with the CLI (`/debug`, `/code-review`, `/loop`...) [skills](https://code.claude.com/docs/en/skills).

**Lifecycle hooks.** `hooks.json` events include `SessionStart` (matchers `startup|resume|clear|compact|fork`), `Setup` (fires with `--init-only`, or `--init`/`--maintenance` in `-p` mode, "for one-time preparation in CI or scripts"), `SessionEnd`, `ConfigChange`, `InstructionsLoaded`; handler types `command|http|mcp_tool|prompt|agent` [hooks](https://code.claude.com/docs/en/hooks). Monitors run background commands; `settings.json` may set `agent` to make a plugin's agent the main thread [plugins](https://code.claude.com/docs/en/plugins). Node deps auto-install with `npm ci --ignore-scripts` from a lockfile [plugins-reference](https://code.claude.com/docs/en/plugins-reference).

**Discovery and distribution.** Marketplace = repo with `.claude-plugin/marketplace.json` {`name`, `owner{name}`, `metadata.pluginRoot`, `plugins[]`, `renames`}; each entry {`name`, `source`, `displayName`, `version`, `category`, `strict`...}; source types: relative `./path`, `github {repo,ref,sha}`, `url` (any git), `git-subdir`, `npm {package,version,registry}`, `archive {url,sha256}` (zip, v2.1.224+), `command` (v2.1.229+) [plugin-marketplaces](https://code.claude.com/docs/en/plugin-marketplaces). Add with `/plugin marketplace add owner/repo | https://...git | ./dir | https://.../marketplace.json`; install `/plugin install name@marketplace` or `claude plugin install name@marketplace --scope project --config k=v --json`; one-shot `/plugin install name --marketplace org/repo` (v2.1.275+) [discover-plugins](https://code.claude.com/docs/en/discover-plugins). Other CLI: `claude plugin init|validate|list|enable|disable|update|uninstall|eval` [plugins-reference](https://code.claude.com/docs/en/plugins-reference). Community marketplace `anthropics/claude-plugins-community` (pinned SHAs, submission forms); official marketplace is curated with no application process [plugins](https://code.claude.com/docs/en/plugins). Container pre-seeding: `CLAUDE_CODE_PLUGIN_CACHE_DIR` at build time, `CLAUDE_CODE_PLUGIN_SEED_DIR` at runtime [plugin-marketplaces](https://code.claude.com/docs/en/plugin-marketplaces). A CLI listed in the official marketplace can print `<claude-code-hint v="1" type="plugin" value="name@claude-plugins-official" />` to stderr when `CLAUDECODE=1` and Claude Code offers to install it [plugin-hints](https://code.claude.com/docs/en/plugin-hints).

**Scopes / overriding.** `user` (`~/.claude/settings.json`), `project` (`.claude/settings.json`), `local` (`.claude/settings.local.json`), `managed`; keys `enabledPlugins`, `pluginConfigs`, `extraKnownMarketplaces`, `strictKnownMarketplaces`, `blockedMarketplaces` [plugins-reference](https://code.claude.com/docs/en/plugins-reference). Skills-dir plugins auto-load from `~/.claude/skills/<name>/` (`claude plugin init` scaffolds there) and `.claude/skills/` as `<name>@skills-dir` [plugins](https://code.claude.com/docs/en/plugins). Marketplace plugins are copied to `~/.claude/plugins/cache/<mkt>/<plugin>/<version>/`; version = marketplace entry > `plugin.json` > commit SHA; auto-update in background [plugin-marketplaces](https://code.claude.com/docs/en/plugin-marketplaces). `claude plugin eval` (v2.1.269+) runs `evals/<case>/prompt.md` + `graders/*.md` three times with/without the plugin and reports Δ [plugin-evals](https://code.claude.com/docs/en/plugin-evals).

**Permissions/sandbox/remote.** Modes: `default` (Manual), `acceptEdits`, `plan`, `dontAsk`, `bypassPermissions`, `auto` (classifier; built-in start mode on Pro/Max/Team); set via `--permission-mode` or `permissions.defaultMode` (`auto`/`bypassPermissions` ignored from project/local files); `--dangerously-skip-permissions` = bypass, refuses under root/sudo unless "inside a recognized sandbox"; `permissions.disableBypassPermissionsMode: "disable"` [permission-modes](https://code.claude.com/docs/en/permission-modes). Bash sandbox: Seatbelt on macOS, `bubblewrap`+`socat` on Linux/WSL2, optional seccomp via `npm i -g @anthropic-ai/sandbox-runtime`, Ubuntu 24.04 needs an AppArmor profile for `bwrap`; `/sandbox`, `sandbox.enabled`, `autoAllowBashIfSandboxed` (default true), `network.allowedDomains`, `allowUnsandboxedCommands:false` [sandboxing](https://code.claude.com/docs/en/sandboxing). Remote Control: `claude remote-control` (server mode, URL + QR, one-time `Enable Remote Control? (y/n)`), `claude --remote-control`/`--rc`, in-session `/remote-control`/`/rc`; requires claude.ai login on Pro/Max/Team/Enterprise (API keys unsupported); execution stays local, transport via Anthropic API [remote-control](https://code.claude.com/docs/en/remote-control).

**Lessons.** Namespacing and marketplace semantics generate most friction: skills not namespaced like commands (#50486), desktop namespacing by install hash (#86627), one pack exposing every marketplace skill (#67679), manifest-less plugins merging namespaces (#76234), marketplace DX (#27541) [search](https://github.com/anthropics/claude-code/issues/50486). Recent direction: `commands/`→`skills/`, `--json` on plugin CLI (2.1.268), evals (2.1.269), npm sources fetched with `--ignore-scripts` (2.1.274), `AGENTS.md` support (2.1.278) [changelog](https://code.claude.com/docs/en/changelog). Claude Code's docs do not mention the cross-vendor root `plugin.json`/`mcp.json` [plugins-reference](https://code.claude.com/docs/en/plugins-reference).

## 2. OpenAI Codex

**Core.** Docs now redirect from `developers.openai.com/codex/*` to `learn.chatgpt.com/docs/*` (HTTP 308, observed). Config: `~/.codex/config.toml`, project `.codex/config.toml` (trusted projects only); `approval_policy` = `on-request` | `never` | `on-failure` (deprecated) | `{granular=...}`, `untrusted` "unsupported"; `sandbox_mode` = `read-only` | `workspace-write` | `danger-full-access`; `[sandbox_workspace_write]` `network_access`, `writable_roots`; `[mcp_servers.<id>]` `command|args|env|url|bearer_token_env_var|enabled`; `[projects."<path>"].trust_level`; `[features]` flags incl. `hooks`, `multi_agent`, `skill_mcp_dependency_install`; `[skills.config]`, `[plugins.<plugin>]`; profiles are files `$CODEX_HOME/<name>.config.toml` selected with `--profile` [config-reference](https://learn.chatgpt.com/docs/config-file/config-reference). CLI: `--sandbox/-s`, `--ask-for-approval/-a on-request|never`, `--dangerously-bypass-approvals-and-sandbox`/`--yolo` ("only for externally hardened environments"), `--full-auto` deprecated → `--sandbox workspace-write`, `--dangerously-bypass-hook-trust`, `codex login --device-auth`, `codex mcp add|list|remove|login|logout|get`, `codex exec` [cli-reference](https://learn.chatgpt.com/docs/cli/reference). Sandbox: Seatbelt on macOS, `bubblewrap` on Linux/WSL2, Windows native or WSL2; UI presets "Ask for approval", "Approve for me", "Full access" [sandboxing](https://learn.chatgpt.com/docs/sandboxing).

**Default experience.** `workspace-write` is "the default low-friction mode for local work" [sandboxing](https://learn.chatgpt.com/docs/sandboxing). Bundled system skills `$skill-creator`, `$skill-installer` [build-skills](https://learn.chatgpt.com/docs/build-skills) and `@plugin-creator` [build-plugins](https://learn.chatgpt.com/docs/build-plugins). Instructions: `~/.codex/AGENTS.override.md` > `~/.codex/AGENTS.md`, then per directory from git root to cwd `AGENTS.override.md` > `AGENTS.md` > `project_doc_fallback_filenames` (one file per dir), concatenated root-down, 32 KiB `project_doc_max_bytes` [agents-md](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

**Extension unit.** Skills follow agentskills.io: `SKILL.md` (`name`, `description`) + `scripts/`, `references/`, `assets/`, optional `agents/openai.yaml` (`interface.display_name/short_description/icon_*/brand_color/default_prompt`, `policy.allow_implicit_invocation`, `dependencies.tools[{type: mcp}]`); invoked as `$skill-name` or `/skills` [build-skills](https://learn.chatgpt.com/docs/build-skills). Plugins bundle skills, MCP servers, hooks, browser extensions/apps; `/plugins` opens a browser in the CLI [plugins](https://learn.chatgpt.com/docs/plugins). Layout: `plugins/<name>/.codex-plugin/plugin.json` + `skills/`, `.mcp.json`, `.app.json`, `agents/`, `commands/`, `hooks.json`, `assets/` [openai/plugins](https://github.com/openai/plugins). `plugin.json` fields: required `name`, `version`, `description`, `author`, `interface{displayName, shortDescription, developerName, category, ...}`; optional `homepage`, `repository`, `license`, `keywords`, `skills`, `hooks`, `mcpServers`, `apps` [plugin-json-spec](https://github.com/openai/codex/blob/main/codex-rs/skills/src/assets/samples/plugin-creator/references/plugin-json-spec.md). A "portable" alternative puts `plugin.json` at root with `"$schema": "https://agent-plugins.org/schemas/1.0.0/plugin.schema.json"` and auto-discovers `skills/` [build-plugins](https://learn.chatgpt.com/docs/build-plugins).

**Discovery and distribution.** Skill search path: `.agents/skills` in cwd, parents, and repo root; `~/.agents/skills`; `/etc/codex/skills`; bundled [build-skills](https://learn.chatgpt.com/docs/build-skills). Marketplaces: `~/.agents/plugins/marketplace.json` (personal, discovered implicitly), `<repo>/.agents/plugins/marketplace.json`, official Plugin Directory; entries need `name`, `source{source:"local", path}`, `category`, `policy{installation, authentication}` [plugin-creator SKILL](https://github.com/openai/codex/blob/main/codex-rs/skills/src/assets/samples/plugin-creator/SKILL.md), [plugin-json-spec](https://github.com/openai/codex/blob/main/codex-rs/skills/src/assets/samples/plugin-creator/references/plugin-json-spec.md). CLI: `codex plugin add|list|remove <plugin[@marketplace]>`, `codex plugin marketplace add|list|remove|upgrade` [cli-reference](https://learn.chatgpt.com/docs/cli/reference). Cache-busting versions `<base>+codex.<timestamp>` [installing-and-updating](https://github.com/openai/codex/blob/main/codex-rs/skills/src/assets/samples/plugin-creator/references/installing-and-updating.md). On-disk plugin cache path: unverified (not in docs). `openai/skills` is deprecated in favour of `openai/plugins` [openai/skills](https://github.com/openai/skills).

**Lessons.** Skills moved to the vendor-neutral `.agents/` tree; `untrusted`/`--full-auto` were retired; docs relocated under ChatGPT. Community asked (2026-03-27) for a self-serve path into the official directory and got no answer; local/repo marketplaces are the only documented third-party route [community thread](https://community.openai.com/t/how-can-third-party-community-plugins-be-published-to-the-codex-marketplace/1377928). Sessions now hot-reload plugin tools/skills/hooks after upgrades (0.154.0) [changelog](https://learn.chatgpt.com/docs/changelog).

## 3. Gemini CLI, Cursor, MCP Registry, and converging conventions

**Gemini CLI.** Extension = directory with `gemini-extension.json` {`name` (lowercase/dashes), `version`, `description`, `mcpServers`, `contextFileName` (default `GEMINI.md`), `excludeTools`, `settings[]` (`name`, `envVar`, `sensitive` → keychain), `migratedTo`, `themes`, `policies`} plus `commands/*.toml` (→ `/deploy`, nested `gcs/sync.toml` → `/gcs:sync`), `hooks/hooks.json`, `skills/<n>/SKILL.md`, `agents/`; installed to `~/.gemini/extensions/<name>/`; variables `${extensionPath}`, `${workspacePath}` [reference](https://github.com/google-gemini/gemini-cli/blob/main/docs/extensions/reference.md). Commands: `gemini extensions install <github-url|path> [--ref] [--auto-update] [--consent]`, `uninstall`, `update [--all]`, `enable|disable --scope user|workspace`, `link <path>`, `new <path> [mcp-server|context|custom-commands]`, `config` [reference](https://github.com/google-gemini/gemini-cli/blob/main/docs/extensions/reference.md). Distribution: git URL or GitHub Releases with `{platform}.{arch}.{name}.tar.gz` assets; gallery at geminicli.com/extensions/browse auto-indexes public repos tagged `gemini-cli-extension` daily [releasing](https://github.com/google-gemini/gemini-cli/blob/main/docs/extensions/releasing.md); launched 2025-10-08 with 25+ partners [discussion](https://github.com/google-gemini/gemini-cli/discussions/10718); official org `gemini-cli-extensions` [org](https://github.com/gemini-cli-extensions). Lesson: extension commands rank lowest and conflicts get prefixed (`/gcp.deploy`) [reference](https://github.com/google-gemini/gemini-cli/blob/main/docs/extensions/reference.md).

**Cursor.** Rules in `.cursor/rules/*.mdc` with `description`, `globs`, `alwaysApply`; supports `AGENTS.md` at root and nested [rules](https://cursor.com/docs/context/rules). Skills from `.agents/skills/`, `.cursor/skills/`, `~/.agents/skills/`, `~/.cursor/skills/`, and compatibility paths `.claude/skills/`, `.codex/skills/` [skills](https://cursor.com/docs/context/skills).

**MCP Registry.** `registry.modelcontextprotocol.io`, preview with API freeze v0.1; `server.json` (`$schema` 2025-12-11) with reverse-DNS `name` like `io.github.<user>/<name>`, `packages[]` (`registryType` npm|pypi|oci|nuget|cargo|mcpb, `runtimeHint`, `environmentVariables`), `remotes[]`; ownership via GitHub OAuth/OIDC or DNS/HTTP; `mcp-publisher init|login|publish`; metadata-only (packages hosted elsewhere) [registry](https://github.com/modelcontextprotocol/registry), [server-json](https://github.com/modelcontextprotocol/registry/blob/main/docs/reference/server-json/generic-server-json.md).

**Converging conventions.** Agent Skills (`SKILL.md`, `name` ≤64 lowercase-hyphen chars matching dir, `description` ≤1024, `scripts/ references/ assets/`, `skills-ref validate`) originated at Anthropic and is adopted by Claude Code, Codex/ChatGPT, Gemini CLI, Cursor, GitHub Copilot, VS Code, OpenCode, Goose, Kiro, Amp, Factory, Roo Code and ~40 others [agentskills.io](https://agentskills.io/), [spec](https://agentskills.io/specification). AGENTS.md is stewarded by the Agentic AI Foundation (Linux Foundation), used by 60k+ repos, "closest wins", supported by Codex, Cursor, Gemini CLI, Copilot, Zed, Warp, Jules, Devin... [agents.md](https://agents.md/); Claude Code added it in 2.1.278 [changelog](https://code.claude.com/docs/en/changelog) alongside `CLAUDE.md`/`.claude/CLAUDE.md`/`CLAUDE.local.md`, `@imports`, `.claude/rules/*.md` with `paths`, managed `/etc/claude-code/CLAUDE.md` [memory](https://code.claude.com/docs/en/memory). Agent Plugins 1.0 (2026-08-06; TSC Amazon, Cursor, Microsoft, OpenAI, Vercel): root `plugin.json` (`$schema`, `name` 1-64 lowercase, `version`, `description`, `author`, `homepage`, `repository`, `license`, `keywords`, `extensions{"com.vendor.x"}`), fixed `skills/` and `mcp.json`, `${PLUGIN_ROOT}`/`${PLUGIN_DATA}`, vendor dirs like `com.example.client/` [spec](https://agent-plugins.org/specification); launch clients VS Code, Cursor, GitHub Copilot, Codex, Kiro; Anthropic not mentioned [AAIF](https://aaif.io/blog/from-skills-and-tools-to-portable-agent-plugins). Net: `.agents/` (Codex, Cursor) and the root-`plugin.json`+`skills/`+`mcp.json` shape are the emerging cross-vendor layout; `.claude-plugin/` and `.codex-plugin/` remain the vendor-native manifests.
